# Justice Trésor Ngom — Academic Website

A responsive, single-page academic profile and research portfolio for Justice Trésor Ngom.

## Files
- `index.html` — website content and page structure
- `styles.css` — base layout and styling
- `theme.css` — colour palette, light/dark appearance, typography and section refinements
- `script.js` — mobile navigation and small interactions

## Preview locally
1. Extract the ZIP file.
2. Open the `justice_tresor_ngom_website` folder.
3. Double-click `index.html` to open the website in a browser.

No build tools or installation are required.
